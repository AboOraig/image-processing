# image-processing
This project addresses a key aspect of image processing in order to provide a progressive, theoretical and practical understanding of modern analysis methods.

Main tasks:
Two-dimensional Fourier Transform (2DFT)
The restoration of images degraded by motion blur and additive noise.
The Karhunen-Loève expansion (KLT), also known as Principal Component Analysis (PCA), in the one-dimensional and then two-dimensional cases.
These tools are then applied to the problem of texture detection.

Technologies: Matlab
